# Vesting

[Git Source](https://github.com/tarasyk9/smart-deployer/blob/67018d55aadc997fe794c3a515538d6ce847f6a5/src/LiniarVesting/Vesting.sol)

**Inherits:** [IVesting](/src/LiniarVesting/interface.IVesting), [AbstractUtilityContract](/src/UtilityContract/abstract.AbstractUtilityContract), Ownable

**Title:** Vesting Contract

Manages token vesting schedules for beneficiaries

<i>

Inherits IVesting, AbstractUtilityContract, Ownable

</i>

## State Variables

### token

The ERC20 token that is being vested

```solidity
IERC20 public token;
```

### allocatedTokens

The total amount of tokens that have been allocated for vesting

```solidity
uint256 public allocatedTokens;
```

### vestings

A mapping of beneficiary addresses to their vesting information

```solidity
mapping(address => IVesting.VestingInfo) public vestings;
```
