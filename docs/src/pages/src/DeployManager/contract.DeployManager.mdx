# DeployManager

[Git Source](https://github.com/tarasyk9/smart-deployer/blob/67018d55aadc997fe794c3a515538d6ce847f6a5/src/DeployManager/DeployManager.sol)

**Inherits:** [IDeployManager](/src/DeployManager/interface.IDeployManager), Ownable, ERC165

**Title:** DeployManager - Factory for utility contracts

Allows users to deploy utility contracts by cloning registered templates.

<i>

Uses OpenZeppelin's Clones and Ownable; assumes templates implement IUtilityContract.

</i>

## State Variables

### deployedContracts

<i>

Maps deployer address to an array of deployed contracts addresses

</i>

```solidity
mapping(address => address[]) public deployedContracts;
```

### contractsData

<i>

Maps registered contract address to it's registration data

</i>

```solidity
mapping(address => ContractInfo) public contractsData;
```

<a id="deploy-address-bytes"></a>

### deploy

Deploys a new utility contract

<i>

Emits NewDeployment event

</i>

```solidity
function deploy(address _utilityContract, bytes calldata _initData) external payable override returns (address);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _utilityContract | `address` | The address of the registered utility contract |
| _initData | `bytes` | The initialization data for the utility contract |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| &lt;none&gt; | `address` | The address of the deployed utility contract |
